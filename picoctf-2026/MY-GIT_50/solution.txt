To get the flag we just need to push a commit with a `flag.txt` file that is authored by someone with the name `root` and email `root@picoctf`.

Git lets us use any email/name combination so this is pretty easy to do.

README.md

### If you want the flag, make sure to push the flag!

Only flag.txt pushed by ```root:root@picoctf``` will be updated with the flag.
