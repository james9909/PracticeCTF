When we connect to the server we see that we can actually ping many different ips. The output of the command appears like it's fed directly into the `ping` command without sanitization.

Assuming that the user input isn't sanitized and that it's directly fed into bash, we can use this opportunity to
run arbitrary commands by adding a ; to our query.

```

script.sh

> nc mysterious-sea.picoctf.net 61531
```
